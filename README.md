# Nails & Makeup – Gestione

Dashboard della titolare di **Nails & Makeup** (stesso modello di Radici): agenda, clienti, richieste (trucco sposa e cerimonia), statistiche, comunicazioni, Fidelity Card, notifiche push, servizi, orari, chiusure, negozio, galleria e regole di prenotazione.

- App delle clienti: repository `Nailendmakeup`.
- Dati: Firebase, progetto `nailsendmakeup`, sotto `saloni/nails/...`.
- Regole di sicurezza: `firestore.rules` (da incollare in Firebase → Firestore Database → Regole).
- Si entra con lo stesso account di titolare della vecchia app: la prima volta diventa titolare anche qui da solo.
